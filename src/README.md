# 脑机接口训练平台系统架构详解

## 1. 系统架构概述

本脑机接口训练平台采用现代化前端三层架构设计，基于React+TypeScript构建，实现了完整的脑电信号采集、处理、分析与反馈闭环系统。系统核心架构围绕实时性和可扩展性设计，确保从信号采集到用户反馈的全流程延迟控制在125ms以内。

## 2. 分层架构设计

### 2.1 数据层

数据层负责EEG信号的模拟、管理和缓存，为上层应用提供统一的数据访问接口。

**核心组件与功能：**
- **数据模拟器** (`mocks/motionImageryData.ts`)：实现高精度EEG信号模拟，包含μ(8-13Hz)和β(13-30Hz)节律成分
- **数据结构设计**：采用标准化的数据结构，包括被试信息、EEG通道数据、大脑活动数据等
- **缓存机制**：实现滑动窗口缓存策略，仅保留最近1000个样本点，平衡实时性与内存占用
- **接口抽象**：提供统一的数据访问接口，支持无缝切换模拟数据和真实采集设备

**数据流向：**
模拟数据源 → 数据缓存 → 业务逻辑层处理 → 状态更新 → 表现层展示

### 2.2 业务逻辑层

业务逻辑层实现信号处理、特征提取和分类算法，是系统的核心处理单元。

**核心算法与处理流程：**
- **小波自适应滤波**：对非平稳EEG信号进行多尺度分解，动态调整阈值抑制噪声和伪迹
- **ERD/ERS特征提取**：采用短时傅里叶变换计算μ/β频段能量变化，提取运动想象相关特征
- **SVM分类器**：实现在线学习支持向量机，基于提取的特征识别用户运动意图
- **实时处理流水线**：采集→预处理→特征提取→分类→结果输出的完整处理链路

**性能优化：**
- 时间复杂度优化至O(n log n)，确保实时处理能力
- 滑动窗口大小500ms，步长100ms，平衡时间分辨率与频率分辨率
- 关键路径延迟控制在125ms以内

### 2.3 表现层

表现层提供用户界面和可视化反馈，采用组件化和模块化设计，支持主试和被试角色分离。

**核心界面组件：**
- **主试控制台** (`pages/ResearcherDashboard.tsx`)：提供实验控制、数据管理和结果分析功能
- **被试训练界面** (`pages/SubjectTraining.tsx`)：提供实验范式和实时反馈功能
- **实验范式组件** (`components/MotionImagery/ExperimentParadigm.tsx`)：实现8秒固定试次流程
- **数据可视化组件**：包括EEG信号图、特征可视化、分类结果等

**交互设计：**
- **可拖拽布局**：基于react-resizable-panels实现模块化仪表盘布局
- **实时反馈机制**：通过小球移动直观展示运动想象识别结果
- **多模态提示**：视觉和听觉结合的实验指导提示系统

## 3. 状态管理架构

系统采用分层状态管理架构，确保数据流向清晰可预测。

**状态分层：**
- **全局状态**：通过React Context API管理用户认证、角色信息等
- **组件状态**：各组件内部管理自身状态，如训练状态、当前试次等
- **数据流**：采用单向数据流设计，确保数据流向清晰可追踪

**核心状态管理组件：**
- **认证上下文** (`contexts/authContext.ts`)：管理用户认证状态和角色信息
- **主题钩子** (`hooks/useTheme.ts`)：管理系统主题切换和持久化

## 4. 系统工作流程

### 4.1 实验准备阶段
1. 用户通过首页进入系统，选择主试或被试角色
2. 主试配置实验参数，包括被试信息、训练类型等
3. 被试进入训练准备界面，接收训练指导

### 4.2 训练运行阶段
1. 主试启动训练，系统进入训练状态
2. 被试界面显示实验范式，包括8秒固定试次流程
   - 提示阶段(2秒)：显示运动想象目标
   - 准备阶段(2秒)：被试准备集中注意力
   - 想象阶段(2秒)：被试进行运动想象
   - 休息阶段(2秒)：被试休息准备下一试次
3. 系统实时采集、处理EEG信号，识别运动意图
4. 系统通过小球移动提供实时反馈

### 4.3 数据管理与分析阶段
1. 系统实时记录训练数据和分类结果
2. 主试可以查看实时分类结果和训练指标
3. 训练结束后，系统保存完整训练数据

## 5. 扩展与二次开发

系统设计考虑了扩展性和二次开发需求，提供了清晰的接口和模块化设计。

**扩展点：**
- **数据接口扩展**：支持接入真实EEG采集设备，只需实现统一数据格式
- **算法插件系统**：支持替换或扩展信号处理、特征提取和分类算法
- **可视化扩展**：支持添加新的可视化组件和展示方式

**开发建议：**
- 如需接入真实采集设备，只需替换`mocks/motionImageryData.ts`实现
- 如需修改实验范式，可调整`components/MotionImagery/ExperimentParadigm.tsx`
- 如需添加新的可视化方式，可扩展`components/MotionImagery`目录下的组件

## 6. 性能与实时性保障

系统采用多种策略确保实时性和高性能。

**实时性优化：**
- 关键路径延迟控制在125ms以内
- 采用requestAnimationFrame实现60fps平滑渲染
- 计算任务优先级划分，保障核心功能实时性

**性能优化：**
- 组件化设计，避免不必要的重渲染
- 数据缓存策略，减少重复计算
- 响应式设计，适配不同设备屏幕

## 7. 总结

本脑机接口训练平台采用现代化前端架构设计，实现了完整的脑电信号处理和反馈系统。三层架构设计确保了系统的可扩展性和可维护性，而精心的性能优化策略保障了系统的实时性要求。系统支持主试和被试角色分离，提供了丰富的实验控制和数据管理功能，同时通过直观的可视化反馈帮助被试进行运动想象训练。

这个架构设计既满足了当前脑机接口训练的专业需求，又为未来功能扩展与性能优化提供了灵活的基础。
